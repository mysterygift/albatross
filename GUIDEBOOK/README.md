# The Albatross Guidebook

A step-by-step guide to running a production in Albatross, written for the desktop app. The iPad and iPhone app has the same pages; what differs is listed in [Finding your way](02-finding-your-way.md#ipad-and-iphone).

New here? Read chapters 1 and 2, then jump to whichever area you need. The chapters follow the order a production usually unfolds.

## Conventions

- **Bold** text is a button, field or menu name exactly as it appears. **Schedule → Stripboard** means open Schedule in the sidebar, then Stripboard.
- ⌘ is the Command key on macOS; use Ctrl on Windows.
- A production is one show: a film, episode set, commercial or documentary. Most pages show data for the production selected in the top bar.

Installing, or macOS/Windows warnings about an unsigned app? See the [README](../README.md#opening-an-unsigned-app).
